# 溢价管理 SOP (每周运维手册)

依据: [`output/experiments/premium_decision.md`](../output/experiments/premium_decision.md) (任务23 决策报告)
及 E1/E2/E3 实验证据。适用范围: 纳指腿 (513100) 的 QDII 溢价管理。
**定位: 运营纪律, 不涉及策略引擎/配置的任何改动; 哨兵只提示、不自动切换。**

## 1. 原则速记

- 生产回测口径 = 场内市价 (含溢价), 历史业绩含溢价 beta ≈+1.2pp/年 (E1)。
- **新增管纪律** (溢价 >1.5% 新增走场外, E3), **存量管监控** (回吐敞口 = w×(p−0.43%)/(1+p)),
  **卖出永远照常场内** (高溢价卖出是受益方)。
- 场外联接执行总代价 ≈0.14pp/年 (E2 lag=2 中枢; 区间 0.10~0.24pp/年), 极便宜——纪律的成本可忽略,
  别为省它破例。**但容量受限购硬约束** (2026-07-31 核实): 周频节奏下场外路径实际仅支持约
  ≤19万 (当日) / ≤94万 (分批极限 ≈5万/周) 资金规模, 且单点依赖华夏一只 (见 §4.2/§6.1/附表1)。
- 任何"存量轮换变现"都是资金层人工决策 (决策报告 §4), 不在本 SOP 的默认动作里。

## 2. 每周调仓日流程 (周一)

```bash
cd /home/ubuntu/claw_etf_strategy
python scripts/update_etf_data_tushare.py                    # ① 数据更新
python scripts/rebalance_live.py --premium-check             # ② 调仓计算 + 溢价哨兵
# ③ 读哨兵输出 → 按 §3 纪律表决定执行通道 → 执行
python scripts/rebalance_live.py --save-state                # ④ 确认成交后保存状态
```

读哨兵输出的要点:

1. **哨兵阈值已与纪律线对齐 (任务28)**: 绿 <1.5%, 🟡 观察区 [1.5%, 2.5%), 🔴 ≥2.5%。
   早期版本哨兵绿色区间 <2.0% 的错位 (决策报告 §5.2) 已在代码中校正, 无需再人工换算。
2. 旧"盈亏平衡 p*≈2.1%"框架已被 E3 证伪并从哨兵文案移除 (哨兵注释已标注), 哨兵只输出
   溢价数值与候选对比表; 如见到历史周志中的 p* 引用, 忽略其依据。
3. 哨兵显示"⚠️ 降级"(数据获取失败) 时: 手工到天天基金/集思录查 513100 实时溢价 (IOPV 口径),
   再走 §3。
4. 执行前 (尤其 🔴 档) 盘中复核实时溢价——哨兵用的是昨收/最新净值, QDII 净值 T+1 有时差噪声。

## 3. 纪律表 (溢价区间 × 新增/存量 × 动作)

p = 513100 最新溢价 (哨兵输出或手工查询)。"新增" = 本周调仓 Δw>0 的纳指腿买入。

| 溢价区间 | 哨兵显示 | 新增/加仓 | 存量持仓 | 卖出 |
|---|---|---|---|---|
| p < 1.5% | ✅ | **场内直接买入** 513100 | 持有 | 场内照常 |
| 1.5% ≤ p < 2.5% | 🟡 观察区 | **场外联接申购** (§4) | 持有; 记录回吐敞口 | 场内照常 |
| p ≥ 2.5% | 🔴 告警 + 候选对比表 | 场外联接申购 (勿因限购改买高溢价场内) | 持有; 回吐敞口记入周志, 触发月度复评议题 | 场内照常 (高溢价卖出是收益) |
| 溢价急崩 (周内 −3pp 以上) | — | 场内买入恢复正常 (p<1.5% 后) | 见 §6.2 | 暂缓非必要卖出 (低溢价卖出吃亏), 引擎强制卖出仍执行 |

补充规则:

- **金额下限**: 单笔新增 <0.5% 组合权重且 p<2.5% 时, 可豁免走场外 (场外 T+2 时序的操作成本
  相对收益不划算), 但须在周志记一笔。
- 回吐敞口速算: `敞口(pp 组合净值) = 纳指权重 × (p − 0.43%) / (1 + p)`。
  例: 21.8% × (10.42%−0.43%)/1.1042 ≈ 1.97pp。
- 哨兵候选对比表 (🔴 档) 仅供参考: 跨标的替代 (513500 等标普) 有纳指/标普收益差损耗,
  E3 已证其劣后 (层b), **不作为新增通道**; 同标的低溢价场内候选可在场外限购时作为备选 (§6.1)。

## 4. 场外联接申赎操作要点

标的: 513100 同指数场外基金 (如国泰纳斯达克100指数 QDII-LOF 160213, 或费率更优的纳指100
联接/指数基金; **优先 C 类** ——0 申购费+销售服务费, 与 E2 的 0.4pp/年持有成本差假设一致)。

### 4.1 T+2 时序 (E2 的 lag=2 中枢即此)

| 日 | 动作 |
|---|---|
| T 日 15:00 前 | 提交申购 (务必在 15:00 截止前; 之后顺延按 T+1 算) |
| T+1 | 基金公司按 T 日净值确认金额 (QDII 净值 T+1 披露) |
| T+2 | 份额确认可查; **对账日** |
| 赎回 | 份额 T 日提交, 款项 T+3 ~ T+7 到账 (应急流动性弱, 资金规划提前留量) |

时序含义: 申购期间资金 1~2 个交易日脱离纳指暴露, 单笔期望成本 ≈0 (E2: 单笔均值 0.6bp,
正成本笔占比 ~50%), 不必为择时纠结。

### 4.2 每笔操作三查 (限购约束后修订 2026-07-31)

1. **限购检查 (强制前置，申购前必做，不得跳过)**: 
   - 登录基金公司官网或天天基金网，查最新公告的 **单日申购限额** (限额随 QDII 额度随时变化,
     不得沿用历史快照)
   - 对标表: 按本 SOP 附表1 对应资金规模的单笔申购需求
   - 分流 (以华夏 1万/日为容量基准, 其余基金 10元/5元/日 容量可忽略):
     * 单笔 ≤1万元: 华夏单只当日申购 (§6.1 路径1)
     * 单笔 1万~5万元: 华夏分 2~5 日申购, 受周频窗口硬约束 (§6.1 路径2)
     * 单笔 >5万元: 场外实质失效, 直接走 §6.1 路径3/4
   - 若华夏限额收紧或暂停: 场外路径整体失效, 直接走 §6.1 路径3/4
   - 当前主流基金限额状态 (2026-07-31 快照, 仅供参考, 执行前必查最新公告):
     * 华夏: 1万元/日 (**唯一有效容量, 单点依赖**)
     * 华安/万家/大成: 10元/日; 广发: 5元/日 (容量贡献可忽略)
     * 暂停: 国泰LOF(160213)、易方达LOF(003722)、嘉实(016532)

2. **确认对账 (T+2)**: 确认份额 = 金额/(T 日净值) − 费用; 确认净值日期是 T 日而非顺延;
   在周志记录: 日期/金额/确认净值/当日 513100 溢价。

3. **口径对账 (与策略状态)**: 场外份额按其净值折算市值, 计入 `rebalance_live` 阈值判断所用
   的实际仓位 (`--save-state` 前人工核对纳指腿合计权重); 场内外合计视为同一个"纳指腿"。

## 5. 月度复评清单 (每月首个调仓日, 约 15 分钟)

- [ ] **溢价水平**: 当月 513100 溢价区间/月末值; 与历史中位 0.43%、2024至今中位 2.89% 对照;
      更新存量回吐敞口 (速算式见 §3)。
- [ ] **QDII 额度政策**: 基金公司限购/放开公告、外汇局 QDII 额度增发新闻——额度放开是溢价
      崩塌的头号催化剂 (见 §6.2 预案)。
- [ ] **候选溢价对比**: 跑 `python scripts/premium_sentinel.py` (手工诊断入口), 记录 6 只候选
      溢价; 若某同标的纳指 ETF 溢价长期 (连续 2 个月) 比 513100 低 3pp 以上, 提请评估换主标的
      (需另立任务, 涉及数据管线, 不在本 SOP 内直接执行)。
- [ ] **存量轮换变现议题**: 若 p ≥ 5% 持续, 复核决策报告 §4 的账目 (敞口/成本/反面情形),
      向资金决策人提交"变现 or 持有"月度意见; **该决策不自动执行**。
- [ ] **周志归档**: 当月场外申赎记录、豁免记录、哨兵降级次数。

## 6. 异常预案

### 6.1 联接基金限购 (新增走不了场外, 2026-07-31 扩充)

**背景**: 限购已成常态。有效容量几乎全部来自**华夏一只** (1万元/日); 华安/万家/大成 (各 10元/日)、
广发 (5元/日) 合计仅 35元/日, 容量贡献可忽略——**不存在有意义的"多基金并行分散"容量**, 场外路径
实质是对华夏限额政策的单点依赖。按单笔申购需求分级执行:

#### 路径1: 华夏单只当日申购 (单笔 ≤1万元, 约对应 ≤19万资金规模)

- 向华夏纳斯达克100 C (限额 1万元/日) 当日一笔完成
- 执行前按 §4.2 强制前置限购检查, 确认华夏限额未收紧/暂停
- 代价: ≈0.14pp/年 (E2 lag=2 中枢总代价; 区间 0.10~0.24pp/年, 最坏情形 lag=1 为 0.24pp/年)
- 周志记录: 日期/金额/确认净值/当日 513100 溢价

#### 路径2: 华夏分日申购 (单笔 1万~5万元, 约对应 19万~94万资金规模)

- **分批规则**: 需求金额 ÷ 华夏日限额 (1万元) = 所需交易日数 (2~5 日)
- **周频硬约束**: 下次调仓 5 个交易日后即到, 分批窗口极窄, 实际可行容量上限 ≈**5万/周**;
  当周完不成的部分不强行延后, 转路径3/4
- **成本口径** (E2 实测, 滞后成本随 lag 递减): 仅滞后成本 lag=1/2/3 分别为
  0.140/0.050/0.013 pp/年——分批确认落在 T+2/3 的部分成本反而更低, 分日本身不额外
  增加滞后成本; 叠加费率差后总代价仍在 0.10~0.24pp/年区间内
- **对账**: 逐日记录 日期/金额/确认净值/T+2确认份额, 全部确认后与纳指腿总权重对齐

#### 路径3: 场内低溢价候选 (单笔 >5万元, 或场外全部限购/暂停)

- **可用候选** (需查哨兵输出或手工查询):
  * 513650 (南方标普500): 例如 4.52% 溢价 (vs 513100 当前 10.86%)
  * 159632 (华安纳斯达克100): 例如 7.89% 溢价 (vs 513100 当前 10.86%)
- **权衡计算**: 
  * 溢价差: 3-6pp
  * 对应一次性回吐敞口 (按 0.094pp/组合净值 每 1pp 权重)
  * 跨标指数损耗: E3已证 <0.5pp/年
  * 决策: 若溢价差 >2pp 且持续，跨标切换性价比优
- **适用场景**: 
  * 单笔需求 >5万元 (约 >94万资金)——周频窗口内华夏分批无法完成, 场外实质失效
  * 主要纳指基金全部暂停申购, 或华夏限额收紧/暂停
  * 当月溢价 >7%，不想冒踏空风险
- **操作**: 按 §3 纪律表，低溢价场内候选视为替代资产，申购无限额限制

#### 路径4: 临时降权/推迟加仓 (最后兜底)

- **触发条件**:
  * 场外实质失效 (单笔 >5万元或华夏限额收紧/暂停)
  * 且场内 (含低溢价候选) 溢价亦处于高位 (>5%)
- **执行**:
  * 推迟该笔加仓一周
  * 在周志记录: 原目标权重、推迟原因、预计执行时间
  * **不产生额外成本**: 踏空风险 <一周期望成本
- **等待契机**:
  * 外汇局 QDII 额度补充政策 (历史规律: 溢价持续 >7% 时通常 1-3 个月内补充)
  * 补充后基金公司迅速放宽限额 (如 2026-07-20 后多只基金从严限放宽)
  * 监控月度复评清单中的"QDII额度政策"一项
- **下周优先补齐**: 额度放宽后，下周调仓日优先完成上周未完成的目标权重

### 6.2 溢价急崩 (如 QDII 额度放开、单周溢价 −3pp 以上)

- **不恐慌卖出**: 急崩伤的是市价不是净值, 策略信号 (动量/波动率) 会通过市价列自然响应,
  Layer3 防御无需人工干预; 人工抢跑卖出等于在最差价格实现溢价损失。
- 存量若在场内: 事后复盘回吐多少 (对照月志的敞口记录), 作为下一次"高溢价是否变现"决策的实证。
- 新增恢复: p 回到 <1.5% 后新增恢复场内直接买入。
- 若此前已转场外 (决策报告 §4 变现方案曾执行): 溢价回到低位 (<0.5%) 时可评估回切场内
  (恢复流动性), 回切本身按 §3 纪律表执行 (低溢价场内买入无障碍)。

#### 溢价回落防线 (E4 实证, 2026-07-31 新增)

**定位**: 本 §6.2 前述条目是溢价急崩的**事后应对** (不恐慌卖出/事后复盘); 本小节将其升级为
**事前预警 (R2) + 事中止损 (R1)** 的机械防线, 与 §6.1 限购预案衔接 (触发动作复用其路径分层)。
证据: [`output/experiments/premium_e4_collapse.md`](../output/experiments/premium_e4_collapse.md)
(脚本 `scripts/_exp_premium_e4.py`; 513100 历史 85 个高溢价 episode / 28 个 severe ≥5pp 下杀,
最凶案例 2020-09 峰值溢价 27.99% 峰值持有人亏 −20.5%)。

**R1 溢价峰值回撤规则 (主防线, 事中)**

- **检查时点**: 每周调仓日 (§2 流程 ② 哨兵输出后), 用收盘口径数据核对; **不做日频/盘中抢跑**
  —— E4 实测同参数日频执行全期 **−0.61pp/年** (vs 周频 +0.82pp/年): QDII 净值披露时差噪声下
  日频反应过度、whipsaw 加倍。
- **数据口径**: p5 = 513100 溢价 (close/nav−1, 哨兵同口径) 的 **5 日均值** (压披露噪声);
  dd20 = p5 距近 20 个交易日峰值的回撤。
- **自动化 (哨兵 v2, 任务28)**: `rebalance_live.py --premium-check` 一并输出 R1/R2 判定
  (单跑用 `premium_sentinel.py --collapse-check`); 溢价历史 = 缓存 CSV
  (`data/experiments/tushare_cache/`) 打底 + 公开源增量 (close: 东财→新浪→腾讯日K,
  nav: 东财 pingzhongdata), **不依赖 tushare token**; 哨兵任何失败只降级提示人工核查,
  不中断调仓主流程。
- **触发条件**: dd20 ≥ 2pp 且 p5 > 1%。
- **触发动作**: 存量纳指腿改走零/低溢价通道 —— 场外容量内 (≈5万/周, §4.2/附表1) 用"场内卖出 +
  场外申购"对倒 (高位卖出恰好变现溢价, 与 §1 "卖出照常场内"一致); 超容量部分走 §6.1 路径3
  换入当时仍低溢价的场内候选; 若板块已同步下杀则候选保护有限, 剩余敞口接受回吐
  (容量物理上限, 非规则缺陷)。
- **恢复条件**: p5 ≤ 1% 或 dd20 收敛至 ≤0.5pp (阈值的 1/4) → 下一个调仓日原路切回场内 513100。

**R2 份额扩张战略预警 (前置信号)**

- **触发条件**: 513100 场内份额 5 日扩张 ≥5% (fund_share 口径, 拆分等公司行为已剔除;
  份额历史 = 缓存打底 + 上交所 ETF 规模公开查询增量, 不可得时哨兵降级提示人工核查)。
- **触发动作**: 不直接动仓位; 升级"红色警戒" —— 当周起 R1 检查改为每日盘后 (仍按收盘价决策),
  并即时复核 QDII 额度公告 (§5 月度项提前执行)。
- **机制与实证**: 额度放开 → 申购放量 → 套利盘砸溢价, 是 QDII 溢价崩塌的经典链条; E4 实证该
  信号信息量全表最强 (IC10 −0.26)、历史触发仅 3 次且几乎无虚惊 (充分非必要 —— 多数下杀无份额
  前兆, 不能作主防线); 2024 至今休眠 (额度冻结) 正是当前溢价持续不崩的机制性支撑,
  **一旦份额重新放量, 是最值得升级警戒的单一事件**。
- **额度冻结期结构性失效 (份额资金流调研补记, 2026-08)**: 513100 在 QDII 额度用尽期份额
  恒为 0 变动 (变动步长量子化 {+500, +300, −200, −3000}; 冻结日均溢价 3.61% vs 变动日
  1.32%), R2 在该时段**永远不会触发**——而这恰是溢价最高的时段。故"份额冻结"本身应作为
  溢价持续高位的**伴随观察指标** (哨兵观察项, 不作 L1 打分因子); 冻结期内溢价高位判断
  改用溢价绝对水平与 QDII 额度公告。证据: `output/experiments/exp_share_flow.md`
  (该因子入策略 |IC|=0.0205 <0.03 门禁 NO-GO; 仅此项副产品结论保留)。
