## 0. 定位与边界

本设计**不是** v4.0 的实现方案，而是**为 v4.0 方向决策提供的一套诊断框架与初步发现**。它回答一个问题：

> v3.1 的 Sharpe 1.61 建立在"5 个 ETF + 2013-2026 历史"上。已有验证（无前视、参数 MC 鲁棒、DSR 显著、OOS 不退化）覆盖了**实现层与参数层**，但**数据层与 regime 层**未覆盖——"选了这 5 个资产 + 这段历史"本身是否带后视？edge 是否绑死在某个 regime？

本设计提供：①一套量化"数据/regime 层过拟合"的方法；②基于原型的初步发现；③诚实的局限性；④v4.0 候选改造方向（待评估）。

**铁律**：当前原型 `data_manifold.py` 只读使用 `run_backtest`，不修改 `src/`、`config/`、生产数据。v3.1 生产回测复现 Sharpe 1.6096/MDD 0.0697 不变（已验证）。

## 1. 核心思路

把"已发生的历史"当成某个**数据生成过程（DGP）的一次实现**，而非真理。拟合 DGP → 在其参数空间扫描 → 用**真实生产策略**跑合成数据 → 拟合响应面 → 积分"好区域体积占比"作为过拟合判据。

与已有方法的区别：
- **vs bootstrap (D1)**：bootstrap 在真实路径附近重采样（去不了没发生过的地方）；流形**调结构参数生成未发生区域**。两者互补。
- **vs 参数 MC 生存测试**：MC 扰的是**策略参数**；流形扰的是**数据生成参数**。正交。
- **vs OOS walk-forward**：OOS 测"参数过拟合"；流形测"数据/regime 过拟合"。

## 2. 方法论

### 2.1 数据生成过程：VAR(1) + 多元 Student-t

$$r_t = \mu + A\,r_{t-1} + \varepsilon_t,\quad \varepsilon_t \sim \text{MVT}(0,\Sigma,\nu)$$

- **μ (5×1)**：各资产周漂移。年化后即平均收益。
- **A (5×5)**：自回归矩阵。`diag(A)` = 各资产 lag-1 自相关（趋势持续性）；`off-diag(A)` = 跨资产 lead-lag。
- **Σ (5×5)**：残差协方差。对角=各资产波动²，off-diag=截面协变。
- **ν**：Student-t 自由度，控肥尾。ν→∞ 退化为高斯。

**为什么选它**：动量轮动策略的机制直接消费这三类结构——A 抓"趋势有没有"（动量燃料），Σ 抓"分化够不够"（轮动空间），ν 抓"尾部多凶"（危机保护压力）。线性 VAR(1) 是最简、可估、可解释的载体。

**拟合**：OLS 逐方程估 μ、A；残差协方差得 Σ；ν 由各残差列 t-fit 的自由度中位数（clip [4.5, 50]）。

### 2.2 四个可解释轴

从拟合 DGP 抽 4 个标量旋钮，每个控一个结构属性，其余钉死现实值（ceteris paribus）：

| 轴 | 数学定义 | 现实值 | 旋钮含义 | 为何对本策略要紧 |
|---|---|---|---|---|
| **ρ** 趋势持续性 | `mean(diag(A))` | 0.004 | `rho_mult` 缩放 diag(A)：0=随机游走，3=强趋势 | 动量层燃料。ρ=0 时"过去赢家"无预测力 |
| **c** 截面相关 | `mean(abs(off-diag(corr(Σ))))` | 0.057 | `c_mult` 缩放相关结构：0=无关，2=放大共振 | 分散度。c 高=齐崩，轮动无意义 |
| **σ** 波动水平 | `scale(Σ)` | 1.0× | `sig_mult`：0.6=平静，1.6=乱 | inv-vol 加权与危机阈值校准在现实波动 regime |
| **μdef** 防御漂移 | `mean(μ[防御资产])` | 年化 7.2% | `mudef_mult`：0=债牛结束，2=双倍 | 防御仓"安全资产"赚不赚钱 |

**为什么是这四个**：一一对应策略四层机制的输入——ρ↔动量、c↔inv-vol/轮动、σ↔危机保护/风险预算、μdef↔防御仓。

**什么被钉死（ceteris paribus）**：进攻漂移 μ_off、A 的 off-diag、Σ 的具体形状、ν。这些不扫，以保证 4 轴干净可读。**已知不对称**：μ_off 未做轴（见局限性 §5.5）。

### 2.3 生成 → 真实回测 → 响应面

1. **生成**：给定 (ρ,c,σ,μdef)，从调参后的 DGP 抽 T 周收益 → 累乘成 NAV → 写成与真实 CSV 同格式文件。
2. **回测**：用 `run_backtest(config, data_path=合成CSV)` 喂进**未改动的生产策略**，端到端跑（含因子计算、防御、止损）。每组合成参数 → 一个 Sharpe。
3. **采样**：拉丁超立方 4D（150 点 × 3 路径）+ realized 处 (ρ,c) 稠密 2D 切片（7×5×5）+ 4 条 1D 扫描。约 740 次真实回测。
4. **响应面**：拟合二阶多项式 `Sharpe ≈ β₀+Σβᵢxᵢ+Σβᵢᵢxᵢ²+Σβᵢⱼxᵢxⱼ`（R²=0.809）。
5. **体积积分**：蒙特卡洛 20 万点在 4D 合理框内求值响应面，数 `Sharpe>0.5` / `>0` / `<0` 的体积占比。**占比=过拟合判据**。

**关键澄清**：20 万点是**多项式求值（毫秒级）**，不是回测。真实回测仅 ~740 次，进程池并行约 1.6 分钟。

### 2.4 交叉验证

- **D1 stationary bootstrap**（非参数）：对真实周收益做块重采样（block=8），重跑回测 200 次。保留真实波动聚集/尾部/regime，测"数据像真实"的 Sharpe 分布。
- **D3 对抗噪声**：对真实收益注入递增高斯噪声，追踪逐周冠军 ETF 改变率（决策翻转）与 Sharpe 衰减。回答"微小抖动会不会翻转策略方向"。

## 3. 当前原型结果（基于 v3.1 数据）

### 3.1 realized 坐标
ρ=0.004（≈随机游走）, c=0.057（分散度高）, ν=4.5（肥尾撞限）, μdef_ann=7.2%, 进攻漂移 纳指20.8%/中证500 5.6%/黄金10.5%。

### 3.2 过拟合判定
体积占比：Sharpe>0 = **92.6%**，>0.5 = **57.7%**，>1.0 = 15.6%，<0 = **7.4%**，<-0.5 = **0%**。响应面 R²=0.809。**判定：稳健盆地，非幸运尖角。**

### 3.3 关键发现（重塑认知）
1. **edge 不是周动量驱动**：ρ≈0 且 ρ 轴近乎平坦（线性系数 −0.06）。策略 1.61 不是"动量轮动"赚的，而是**防御资产漂移 + 低相关分散 + 低波动环境**赚的。所谓"动量轮动"在周尺度是装饰。
2. **最脆弱轴 = 波动率**（线性 −3.0）：σ 高于现实策略垮（1.0→1.6，Sharpe 0.76→0.18）。策略**结构性 short-vol 倾向**。
3. **regime 风险 = μdef**（线性 +0.66）：μdef→0（债牛不重复）Sharpe 0.74→0.48 且 p5 转负。这是 **M2 selection bias 的量化体现**——edge 绑在"刚好选了处于牛市的防御资产"上。

### 3.4 交叉验证一致
D1 bootstrap Sharpe p5/p50/p95 = 0.64/1.21/1.67，0% 为负。realized 1.61≈p95（headline 偏好运，典型 Sharpe~1.21）。D3：10% 噪声→翻转 7%、Sharpe 1.56；100% 噪声→翻转 69%、Sharpe 0.64（仍非负）。**两法与流形结论一致**。

## 4. 局限性分析（审核重点）

我把这套方法的洞一一摊开，**不替它辩护**。每条都直接影响"判定能否采信"。

### 4.1 DGP 是单一参数族，覆盖不完整
VAR(1)+t **结构性产不出**真实金融数据的若干特征：
- **波动聚集（GARCH）**：ε_t iid，无 vol regime 持续性。→ manifold 内 Sharpe 系统性偏低（realized 0.7-1.1 vs 真实 1.61）。
- **regime 突变**（2015/2020 式断裂）：平稳连续变化测不到结构崩塌。
- **非椭圆/不对称尾部依赖**（跌时齐跌、涨时分化）：MVT 对称椭圆，低估危机同跌。
- **时变相关**（危机时相关飙升）：Σ 固定。
- **多周动量**（4-12 周自相关）：只 lag-1 的 diag(A) 可见，长周期趋势结构不可见。

**后果**：合成数据是"VAR(1)+t 味"的，不是"任意真实可能数据"。绝对 Sharpe 水平被压低，相对结构（哪轴重要、好方向）更可信但仍条件于模型族。

### 4.2 4 轴是条件切片，非全空间均匀扫描
只扫 4 个标量旋钮，其余维度钉死现实值。这是 ceteris paribus 灵敏度，不是"所有可能数据"的均匀覆盖。**覆盖既不均匀也不完整**。

### 4.3 响应面近似误差
二阶多项式 R²=0.809 → 19% Sharpe 方差未捕获。若真实响应面有悬崖/多峰，多项式抹平 → 体积占比（57.7%/7.4%）是平滑估计。**方向性结论（哪轴重要）由直接回测的 2D 切片+1D 扫描给出，不依赖多项式**；但体积数值依赖。

### 4.4 σ 轴方向最不可信
VAR(1)+t 无波动聚集/regime 转移 → 在其世界里"低波动"纯好事（噪声小→信号清）。但现实**超低波动常是崩盘前 complacency 陷阱**（2015/2018/2020 初）。模型产不出、测不到这种"低 vol 是陷阱"的结构。**"低 σ 更好"在 manifold 内成立，外推到真实长期须打折扣**，可能部分是 iid 假设的假象。

### 4.5 μ_off 不对称
进攻漂移（纳指/中证500/黄金的 μ）未做轴，只 μdef 做了。selection bias 的另一半（"进攻资产刚好也牛市"）没测。可加第 5 轴对称化。

### 4.6 绝对水平偏移
manifold 内 realized Sharpe 0.7-1.1 < 真实 1.61（因模型平滑掉波动聚集/多周动量）。**绝对数不可直接当真实预期**，只可用作相对比较。yp_realized=0.64 < 切片实测 1.12，是全局多项式压低局部值所致，体积占比偏保守。

### 4.7 认识论边界（最重要）
D1（非参数）+ 流形（参数化）一致，只证明结论在**"近现实结构"的数据上**稳。**结构迥异的数据**（真正的 regime-switching 世界、不同 tail-coupling）**两法都没测到**。"稳健"判定 = "在像现实的数据上稳健"，**不等于**"在所有可能数据上稳健"。要补这个洞，需 D4 跨 universe 验证或更富 DGP。

### 4.8 过拟合度量本身待商榷
"好区域体积占比"隐含假设：4D 框内各点等可能。但现实数据并非均匀落在框内——某些区域（如 σ 极低+μdef 极高）可能根本不会发生。**未加权的体积占比可能高估或低估真实过拟合度**。可改用"压力情景集"加权（见 §5.2）。

## 5. v4.0 候选改造方向（待评估，非计划）

### 5.1 诊断侧增强（工具升级）
- **富 DGP**：regime-switching VAR（Markov 两态）/ DCC-GARCH（时变相关）/ vine copula（不对称尾部）。直接补 §4.1 的洞。
- **加 μ_off 第 5 轴**：对称化 selection bias 测试。
- **GP 响应面**替代多项式：捕捉非线性，提体积积分可信度。
- **D4 跨 universe 验证**：把同一套规则套到**预承诺的、完全不同的篮子**（行业 ETF/海外/商品），冻结不选。若陌生篮子 Sharpe 量级接近 → 因子真；只在本篮子灵 → selection bias 实锤。**这是测 §4.7 的真正补刀。**

### 5.2 策略侧改造（真正的 fix，v4.0 基石候选）
诊断只是工具，**策略升级**才是 v4.0 的价值：
- **vol-regime 自适应**：危机/防御阈值随**当前**波动水平 re-scale（如用滚动 vol z-score 替代固定历史百分位）。把"绑死 regime"变"跟随 regime"。
- **μdef regime 监控**：防御资产漂移的滚动估计，漂移消失时自动降防御仓位或切换防御标的。
- **selection 去后视**（接 M2/用户大想法）：universe 选择规则化、ex-ante 冻结，让"选什么防御资产"不依赖后视的债券牛市。

### 5.3 度量升级
- 用**压力情景集**（2022 利率冲击年、动量连续反转年、低-vol-后突变年等显式构造）替代/补充"均匀体积占比"，作为验收闸门。

## 6. 待审核的开放问题

1. **VAR(1) 够不够**，还是 v4.0 直接上 regime-switching VAR？后者更真但更难解释、更难定位 realized 点。
2. **"好区域体积%"是否对的过拟合度量**，还是该用压力情景集 + bootstrap CI 双闸门？
3. **σ 轴 short-vol 发现是否真**？需 D4 + 富 DGP（带波动聚集）交叉验证后才能定策略改造方向。
4. **v4.0 目标到底定位成"诊断更准"还是"策略 regime 自适应"**？前者是工具迭代，后者才是策略升级。这决定资源投向。
5. **μdef/μ_off 的不对称**是否在第一轮就对称化，还是先定性确认 μdef 主导后再加？
6. 用户自述的**"大策略想法"**（与 M2 相关）与本设计如何衔接？若大想法是"动态 universe"，本设计的 §5.2 selection 去后视是它的方法论前置。
