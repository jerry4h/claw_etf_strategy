3. 好区域体积占比 — 过拟合判据

在合理数据空间 (ρ×[0,3], c×[0,2], σ×[0.6,1.6], μdef×[0,2]) 内蒙特卡洛 200,000 点积分。占比越大=策略在更多可能数据上有效=非偶然；占比小=只靠刚好这组资产这段历史=过拟合。

4. 1-D 敏感性扫描

红虚线=realized。看哪条曲线在 realized 附近陡降=该维脆弱。

5. D1 非参数交叉验证 — stationary bootstrap Sharpe 分布

bootstrap 保留真实波动聚集，与 VAR 参数化流形结论交叉验证。p5>0 则 edge 统计显著；p5 越接近 0 越脆。本次 n=200, block=8。

6. D3 对抗扰动 — 决策翻转曲线

对真实收益注入递增噪声。蓝线 Sharpe 衰减，红虚线=逐周冠军 ETF 改变的比例。翻转率骤升处即"微小抖动翻转策略"的阈值。

最负线性轴 = volatility (x realized)（系数 -2.998）。即此维偏离 realized 朝不利方向时策略最先垮。
方法论边界（必须读）：VAR(1)+Student-t 是 realized 点附近的局部线性生成模型，极端区域可能失真；故用 D1 bootstrap（保留真实波动聚集）交叉验证。 两结论一致才可信。响应面为二阶多项式近似，R²=0.809；R² 低说明非线性强、体积占比仅供参考。 PE 过滤器在当前策略评分路径未消费（仅计算），故合成 NAV 无 PE 失配问题；进攻资产漂移 μ_off 固定为 realized（未做轴），与 μ_def 不对称——若需对称可扩第5轴。
