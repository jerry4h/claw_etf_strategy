## 0. 背景与假说

v4.4 闭环发现: CCC c_mult 正定性上限使进攻对相关最高只能推到 ≈0.31 (够不着 Layer 3.5 的 0.60 阈值), 而旧 c_mult 版 corr_crisis_combo 中位 MaxDD 13.78% 穿破 12% 红线——破线来自"半吊子相关+波动放大"。**盲区假说**: 0.3–0.5 持续中等相关既造成分散化实质失效、又永远不触发 Layer 3.5, 即"高损伤 + 零触发"。

**DGP 构造**: 复用生产 `gen_regime_corr` (两状态 Markov), 取 `p_enter=1.0, p_stay=1.0` 使全程停留危机态 → 持续恒定中相关; `rho_crisis` 参数化 0.30–0.85, 叠加 `sig_mult` 1.0/1.25/1.5。**名义 vs 实际**: rho_crisis 作用于创新项相关阵, 经 VAR(1) 交叉项与逐资产 GARCH 独立波动路径稀释后, 实现的周收益样本相关低于名义值 (下表 `实际|ρ|` 列, 如名义 0.40 → 实际 ≈0.34), 解读曲面以实际值为准。

## 4. 结论与 v4.5 建议

**Q1 — 盲区假说(高损伤+零触发)是否成立? → 半成立, 需修正为"高损伤+响应不足"。**

- **高损伤半边成立且形态显著**: MaxDD 曲面沿相关轴呈**灰区驼峰**——σ×1.5 下 v4.3 中位 MaxDD 从 base 的 11.27% 单调升至 rho=0.50 的 12.80%(灰区峰值, 破 12% 红线), 而显性危机 rho=0.85 反而回落到 10.97%(不破线)——相关性"半吊子"确实比真危机更伤, 与 v4.4 闭环时的机理推断一致。
- **零触发半边被数据否定**: 灰区格点 Layer 3.5 触发率 22–60%(远非零), 因为持续中相关 + 26 周窗口的采样噪声会频繁把估计值推过 0.6。真正的问题是**响应不足且噪声驱动**: 触发时平均 boost 仅 ≈0.10–0.12(σ×1.5 行), 触发由估计噪声而非真实相关水平决定, 防御加成时断时续, 挡不住持续分散化劣化叠加波动放大。
- **v4.4 EWMA(hl=8) 对盲区无实质改善**: 全部灰区格点 v4.4 与 v4.3 的中位 MaxDD 差 < 0.1pp(最恶劣格 12.81% vs 12.80%)——EWMA 只加快对相关*飙升*的响应, 不改变 0.60 阈值下对*持续中相关*的响应量。

**Q2 — 12% 红线破位边界在哪里? → 仅 σ×1.5 列破线, 且为边际穿破。**

- σ×1.0 与 σ×1.25 下全部灰区格点安全(最高 10.67%); σ×1.5 下名义 rho≥0.30 即破线(12.09%→12.80% 随 rho 单调走高), 最恶劣组合 rho=0.50×σ1.5: v4.3 中位 12.80% / 最差 seed 33.96%。注意破线量级为 +0.1~0.8pp 的**边际穿破**, 且纯波动放大 base×σ1.5 本身已达 11.27%(贴线)——灰区相关的**净增量贡献约 +0.8~1.5pp**, 是压垮红线的最后一根稻草而非主因。

**Q3 — 历史现实性: 盲区是真实威胁还是纯理论构造? → 相关水平真实常态, 损伤组合纯理论。**

- EWMA(hl=8) 进攻对相关落在 0.3–0.5 的时间占比高达 **39.8%**(p50=0.374)——灰区相关不是罕见危机而是**本资产组的常态**; 但历史上它从未与持续 σ×1.5 级波动放大同时出现: 56 个灰区段(中位 3 周, 最长 15 周)内 v4.3 段内 MaxDD 全部 ≤3.0%, 灰区周策略年化收益 +14.0% 不逊于其余周 +13.8%。**盲区损伤 = "常态相关 × 13 年持续 1.5 倍波动"的合成尾部组合, 历史上未发生过**; 但正因相关端是常态, 一旦进入持续高波动期即会自动落入该格点, 不能因历史未现而豁免。

**Q4 — 候选机制推荐: M-C (EWMA 中阈值分级斜坡) 最有希望。**

- **M-C (EWMA thr 0.45, slope 0.75)**: 4 个破线格点全部拉回红线内(12.24–12.80% → 11.37–11.64%), realized Sharpe 1.507(+0.019) / MaxDD 持平 5.84%, 触发率 33.5%(适中), 0.85 显性危机格零劣化——**唯一在三个维度(盲区/realized/显性危机)都不吃亏的方案**。
- M-A (classic thr 0.30, slope 0.5): 盲区改善幅度最大(最低压到 10.99%), realized 也无损(1.494/5.84%), 但触发率 63.5%——Layer 3.5 从"危机开关"退化为"常开的连续调节器", 机制语义漂移大, 摩擦与审计成本更高。
- M-B (相关×波动门控): **否决**。最恶劣格 0.5×σ1.5 完全未修复(12.80% 不变)——持续 sig_mult 放大下短/长期 vol 比 ≈1, 门控恒关; 它防的是"波动突变", 而盲区损伤恰恰来自"持续高波动", 机制与威胁形态错配; realized Sharpe 还倒扣 0.019。

**v4.5 建议**:

1. **优先级评估**: 盲区确认存在但威胁等级为**中低**(边际破线 + 历史未现的合成组合)。若 v4.5 有更高优先级议题, 可接受暂不处理; 若处理, M-C 方向收益/成本比最好。
