# 实验报告: 进攻池 纳指ETF(513100) → 标普500ETF(513500) 替换定量评估

任务ID: 16 | 策略: v4.4 (相关性危机轴闭环生产版) | 引擎零改动, 仅换数据列

## 0. TL;DR

- 全期(2013-08-30~2026-07-24): 换标普后年化 14.51% → 13.23% (**-1.28pp**), Sharpe 1.498 → 1.367 (-0.132), MaxDD 5.85% → 7.05%
- OOS(2024-04-03起): 年化差 -2.82pp, Sharpe差 -0.221
- 盈亏平衡溢价 p*: **每次买入平均多付(且卖出前回吐)超过 2.12% (回测口径) / 2.85% (理论上限口径) 时, 换标普才划算**
- 513100 真实溢价: 历史常态中位 0.44%, 但近1年中位 5.72%、近3月中位 8.38% —— **当前溢价已远超 p\***; 若预期溢价回归常态, 现在买入 513100 的预期损耗超过替换损失

## 1. 数据来源与处理

- **513500 数据源**: 东方财富公开K线 fqt=1 前复权 (tushare token 被服务端拒绝 code=40101)
- tushare token 经直连 API 验证被服务端拒绝 (code=40101 "您的token不对"), 属 token 失效而非权限不足;
  降级采用东方财富公开 K 线接口 fqt=1 前复权, 与 tushare fund_daily+fund_adj 的 QFQ 同口径, 为真实场内行情, 非合成数据。
- 513500 上市交易日 2014-01-15 (基金成立 2013-12-05, 上市前无场内价格),
  周线拼接点 2014-01-17; 2013-05-17 起的缺口 **35 周**用
  SPX(美元) × USDCNH 人民币计价代理按周收益率反向回填 (未含 QDII 跟踪误差/费率, 略偏乐观)。
- 周线对齐: 既有 CSV 周日期(周五快照) asof 取 ≤ 该日最近日收盘, 与 update_etf_data_tushare.py 拼接口径一致。
- 核对: 拼接点后 513100 vs 513500 周收益相关性 = 0.785 (量级合理)。
- 回填影响评估: 见 §2.3 无回填敏感性窗口 (2014-01-20 起双版本对比), 结论方向不变。

### 4.3 盈亏平衡点

- 回测口径 (年化替换损失 1.28pp): **p\* = 2.12%**
- 理论上限口径 (年化 1.72pp): p\* = 2.85%
- 含义: 只有当 513100 **每次买入平均多付的溢价** (买入溢价 − 卖出时残余溢价) 超过 p\* 时, 换标普才划算。
- 若溢价是持续性的(买入高溢价、卖出时溢价仍在), 实际损耗只有溢价的**变动部分**, 有效成本远低于表观溢价, p\* 更难达到。

若长期采用标普版, step_low/step_high 系按纳指 vol 分布校准, 对标普偏松(更少触发防御), 方向上应下调两阈值以恢复同等防御灵敏度 —— 本实验按任务约束只诊断不调参。

## 6. 结论

1. **替换损失不可忽略**: 全期年化 -1.28pp (OOS 段 -2.82pp), 主因是重叠期纳指对标普 5.32pp/年 的收益差, 且该列平均仓位约 17%。
2. **风险端没有获得补偿**: 虽然标普资产本身 vol 更低, 但防御阈值系按纳指 vol 校准, 换标普后防御触发系统性变松(§5), MaxDD 反而上升 (5.85% → 7.05%), Calmar 2.48 → 1.88, Sharpe -0.132 —— 收益、风险双双变差。
3. **溢价视角(关键变量是“买入溢价−卖出时残余溢价”的预期差, 而非溢价绝对水平)**: 盈亏平衡点 p\*≈2.1%。历史常态溢价(全样本中位 0.44%)下买卖对称、损耗≈ 0, **保留纳指明显更优**; 但当前溢价已升至近3月中位 8.38% / 近1年中位 5.72%, 若预期向常态回归, 现在新买入 513100 的预期单次损耗≈ 7.9pp, 远超 p\* —— **在当前高溢价时点新增买入, 换标普(或暂停新增纳指买入)是划算的**; 若溢价系 QDII 额度约束下的结构性高位、长期不回落, 则买卖对称、实际损耗接近 0, 留纳指仍更优。
4. **可操作建议**: 把溢价当作切换开关 —— 溢价 < p\*(2.1%)时用 513100, 持续显著高于 p\* 且预期回落时新增仓位改用 513500。若长期切换, 防御触发阈值需按标普 vol 分布重校准 (§5), 否则防御层灵敏度系统性偏松。
