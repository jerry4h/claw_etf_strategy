## 1. 实验设计

v4.3 的防御参数是 LHS（拉丁超立方）优化产物，精确到四位小数（def_alloc=0.3492 等）。
若参数邻域真的平坦，圆整后性能应几乎不变；若显著变化，则是"薄峰"（过拟合到参数空间尖点）证据。

| 参数 | 基线 v4.3 | A 细圆整 (rounded_fine) | B 粗圆整 (rounded_coarse) |
|------|-----------|------------------------|--------------------------|
| defense.def_alloc | 0.3492 | 0.35 (+0.23%) | 0.35 (+0.23%) |
| defense.step_low  | 0.0764 | 0.075 (−1.8%) | 0.08 (+4.7%) |
| defense.step_high | 0.384  | 0.38 (−1.0%)  | 0.40 (+4.2%) |
| defense.max_def   | 0.8299 | 0.83 (+0.01%) | 0.85 (+2.4%) |

实验C：在基线上仅新增并开启 `ashare_vol` 段（M3 中证500 vol 危机加成）。经阅读
`src/strategy.py`（load_config，`raw.get('ashare_vol', {})`）确认 YAML 路径与代码默认参数：

```yaml
ashare_vol:
  enabled: true          # ashare_vol_boost_enabled，引擎默认 false
  crisis_threshold: 0.90 # 中证500 vol 过去~2年百分位触发阈值
  max_boost: 0.15        # 最大防御加成
  slope: 1.5             # 线性斜率
  pct_window: 104        # 百分位回看窗口(周)
```

机制（`src/engine_core.py::compute_ashare_vol_boost`，`src/backtest.py` L375-378 调用）：
当中证500ETF 年化波动率在过去 104 周中的百分位 > 0.90 时，防御比例加成
`min((pct − 0.90) × 1.5, 0.15)`，与纳指相关性危机加成（crisis_correlation）叠加后 clip 到 1.0。

## 4. 实验C补充：ashare_vol_boost 触发统计

由新增脚本 `scripts/_exp_ashare_trigger.py`（只读复用 src 模块，复刻回测数据管线）统计：

- **触发周数：76 / 662 = 11.48%**；boost 均值 0.096，其中 20 周打满 max_boost=0.15。
- 触发年份分布：2013(1)、2014(7)、**2015(19)**、**2018(16)**、2019(2)、2022(9)、**2024(22)**。
- 命中了设计目标场景：2015 股灾（连续 19 周，多数打满 0.15）、2018 熊市、2024 波动放大期
  ——这些正是"纳指触发器抓不到的 A 股本土危机"。

**但对绩效的净影响近乎为零**：年化 −0.07pp、波动 −0.08pp、Sharpe +0.007、MaxDD 完全不变。
原因：(1) 触发时基线防御比例往往已被 step_high/危机相关性加成推高，加成后又被 max_def/clip
吸收，边际防御增量有限；(2) 2024-09 的 MaxDD 事件虽然当年触发 22 周，但回撤主因是防御资产
与进攻腿同步回撤，追加防御比例无法规避。

## 5. 结论

1. **参数平坦性成立，无薄峰证据。** 细圆整（≤2% 扰动）与粗圆整（≤5% 扰动）后，
   Sharpe/年化/MaxDD/Calmar/周胜率变化均在 ±0.007 / ±0.07pp 以内，远小于 bootstrap 噪声带
   （不足带宽 1%）。v4.3 防御参数邻域是平坦高原而非尖峰，LHS 优化的四位小数精度**无实质意义
   但也无害**；实盘可放心使用圆整值（如 0.35/0.075/0.38/0.83）而不损失性能，配置可读性更好。
2. **ashare_vol_boost 开启的利弊**：
   - 利：机制按设计意图工作（11.5% 周触发，集中于 2015/2018/2022/2024 A股危机期），
     微降波动（7.64%→7.56%）、微升 Sharpe（+0.007）与周胜率（+0.3pp），方向上是防御性改进。
   - 弊：年化 −0.07pp、Calmar −0.02，且 MaxDD 毫无改善（回撤事件结构不变）；
     全部差异都在噪声带内，**没有统计证据支持其增益**，却增加一层机制复杂度与 5 个参数。
   - 建议：维持生产默认关闭。若未来出现"A股本土急跌而纳指平静"的新危机形态再评估，
     或将其列为 OOS 泛化门（Stage C）候选特性单独验证。
3. **一致性核查**：三个变体回测周数（662）、防御周数、MaxDD 事件日期均与基线一致，
   差异纯粹来自防御比例的微小连续变化，符合"参数连续、结构不变"的预期。
